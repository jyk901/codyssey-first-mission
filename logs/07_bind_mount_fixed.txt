# 원인 진단: E: 드라이브는 이동식(Removable, FAT32) → Docker(WSL2)에서 비어 보임
$ docker run --rm -v "E:/.../bind-demo:/t:ro" alpine ls -la /t   → (빈 디렉터리)
$ docker run --rm -v "C:/Users/jyk90/codyssey/bind-demo:/t:ro" alpine ls /t
index.html
